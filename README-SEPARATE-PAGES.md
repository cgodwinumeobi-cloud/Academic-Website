# Separate-page navigation update

This package preserves the existing website files and replaces the Research and Services dropdown anchors with separate Quarto pages.

Research dropdown: research.qmd (overview), research/interests.qmd, research/publications.qmd, research/academic-presentations.qmd, research/funding.qmd, research/other-presentations.qmd.
Services dropdown: services.qmd (overview), services/professional-activities.qmd, services/speaking-engagements.qmd, services/research-tools.qmd, services/volunteering.qmd, services/collaborations.qmd.
Blogs & Reflections stays as separate pages. Podcast, Events, Teaching, and About Me stay as they were.

INSTALLATION: Back up your current site first. Extract the archive and copy its contents into your current project folder. Keep your CURRENT working index.qmd and images/ directory if those are newer than the files in this package. Do not delete any existing blog posts or media. Run `quarto preview` from the project root. Quarto has not been run on this package here.
